## 🎀 Sobre o projeto

O **Prompt Garden** é meu portfólio pessoal de prompts e experimentações com Inteligência Artificial, desenvolvido a partir da minha jornada como **Google Student Ambassador 2026**.

O projeto reúne instruções cuidadosamente estruturadas para explorar o potencial do Gemini e de outras ferramentas do ecossistema Google AI em diferentes contextos: educação, carreira, produtividade, criatividade e tecnologia.

Mais do que reunir comandos, a proposta é demonstrar como a engenharia de prompts pode transformar necessidades reais em experiências úteis com IA.

🌱 Cada prompt representa uma ideia, uma experimentação ou uma possibilidade de aplicação da Inteligência Artificial no cotidiano.

## ✨ Objetivos

- Explorar as possibilidades do Gemini e do ecossistema Google AI.
- Desenvolver prompts estruturados para situações reais.
- Compartilhar conhecimento sobre engenharia de prompts.
- Incentivar o uso criativo, crítico e responsável da IA.
- Criar um acervo pessoal de experimentações e aprendizados.

## 🪄 Como utilizar os prompts

1. Escolha uma categoria.
2. Abra o arquivo do prompt desejado.
3. Copie o conteúdo completo.
4. Acesse o Gemini ou a ferramenta indicada.
5. Personalize as informações entre colchetes.
6. Envie o prompt e refine o resultado conforme necessário.

**Dica:** os melhores resultados geralmente aparecem quando você fornece contexto, objetivo e critérios claros para a IA.

---

## 🧠 Engenharia de Prompts

Os prompts deste repositório seguem uma estrutura que busca melhorar a clareza e a qualidade das respostas.

| Elemento | Função |
|---|---|
| Role | Define o papel que a IA deve assumir. |
| Context | Apresenta o cenário e as informações necessárias. |
| Objective | Explica o que precisa ser realizado. |
| Instructions | Determina as etapas e orientações. |
| Constraints | Define limites e requisitos. |
| Output Format | Especifica como a resposta deve ser apresentada. |
