bem planejada e com identidade visual consistente.

DIREÇÃO CRIATIVA:

1. CONCEITO
Defina uma ideia visual coerente com o objetivo.

2. COMPOSIÇÃO
Determine:
- Elemento principal.
- Hierarquia visual.
- Distribuição dos elementos.
- Profundidade.
- Iluminação.
- Enquadramento.
- Espaços negativos.

3. IDENTIDADE
Defina cores, texturas, tipografia e linguagem visual.

4. PROMPT FINAL
Escreva um prompt detalhado para a ferramenta de
geração de imagens.

5. CONSISTÊNCIA
Se forem várias imagens, preserve:
- Paleta de cores.
- Estilo artístico.
- Iluminação.
- Tipografia.
- Proporções.
- Identidade visual.

6. RESTRIÇÕES
Inclua instruções para evitar:
- Textos ilegíveis.
- Elementos duplicados.
- Objetos deformados.
- Informações inventadas.
- Marcas d'água.
- Poluição visual.

IMPORTANTE:
Não escolha um estilo aleatório.
Todas as decisões visuais devem ter relação com o
objetivo e com o público da peça.

Quando houver referência visual, analise-a antes
de escrever o prompt.
